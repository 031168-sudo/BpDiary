# Дневник гипертоника

Android-приложение (Kotlin + Jetpack Compose + Room) для самоконтроля давления на фоне лечения.

## Сборка
1. Распаковать архив, открыть папку `BpDiary` в Android Studio (Ladybug или новее).
2. Дождаться Gradle Sync, нажать Run — или `./gradlew assembleDebug`, APK будет в `app/build/outputs/apk/debug/`.

minSdk 26 (Android 8.0), targetSdk 35. Все данные хранятся только на телефоне (Room, `bp_diary.db`).

## Что умеет
**Дневник** — замеры (верхнее/нижнее/пульс, время, рука, отметка аритмии, заметка), цветовая категория сразу при вводе,
отметки «принял» по каждому приёму лекарства на сегодня.

**Графики** — давление и пульс за 7/30/90 дней/год, линии цели 135/85, аномалии обведены,
пунктиром отмечено начало каждого препарата. Сводка: средние, диапазоны, утро/вечер, % в цели.

**Анализ**
- *Стабилизация* (последние 14 дней): стабильно в цели / стабильно, но выше цели / снижается / растёт / сильно колеблется,
  и с какого дня держится текущий уровень. Наклон считается по Тейлу–Сену, разброс — по MAD, поэтому один случайный
  скачок не ломает оценку.
- *Лучше или хуже*: этот месяц против прошлого, либо 30 дней против предыдущих 30 — среднее, % в цели, разброс,
  частота аномалий, итоговый вердикт.
- *Тенденция* за 30 дней (мм рт. ст. в неделю).
- *Эффект лекарств*: давление за 14 дней до начала против давления после 14-го дня приёма (раньше — предварительная оценка),
  % отмеченных приёмов, давление в дни без пропусков и с пропусками.
- *Аномалии*: ≥180/110, <90/60, аритмия, пульс >100 или <50, и резкие отклонения от *личной* нормы
  (медиана предыдущих 14 дней, порог 3·MAD, но не меньше 15 мм).

**PDF для врача** — сводка, сравнение с предыдущим периодом, стабилизация, лекарства с оценкой эффекта,
графики и таблица всех замеров с подсветкой отклонений. Отправляется через «Поделиться».

## Нормы
Категории по ESC/ESH (совпадают с клиническими рекомендациями МЗ РФ): оптимальное <120/80, нормальное 120–129/80–84,
высокое нормальное 130–139/85–89, АГ 1 ст. 140–159/90–99, 2 ст. 160–179/100–109, 3 ст. ≥180/110.
Цель для домашних измерений — <135/85. Пороги лежат в `analysis/Analyzer.kt` — при необходимости их меняют там
(например, если врач назначил индивидуальную цель).

## Структура
```
data/      Entities.kt (замер, препарат, отметка приёма), AppDatabase.kt (DAO + Room)
analysis/  Analyzer.kt — вся логика анализа, без зависимостей от Android
report/    ChartRenderer.kt — графики (общие для экрана и PDF), ReportPdf.kt
ui/        App.kt (тема, навигация), Diary/Charts/Analysis/MedicationsScreen, MainViewModel
```

Анализ носит информационный характер и не заменяет врача.
